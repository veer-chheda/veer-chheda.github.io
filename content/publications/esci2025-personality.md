## Abstract

Automatic Personality Prediction (APP) from text
is an upcoming task in Natural Language Processing (NLP).
It has a broad set of applications such as in personalized
systems, social media analysis and empathetic dialogue agents.
Our paper presents a rigorous comparative analysis of classical
machine learning models (Random Forest, XGBoost, SVM)
and a transformer based architecture for Myers-Briggs Type
Indicator (MBTI) prediction using the MBTIBench dataset. A
key contribution of our work is a dual task psycholinguistic
evaluation framework which assesses models on both multi label
classification of discrete MBTI types and multi output regression
of continuous dimension scores. We also move beyond predictive
accuracy and into explainability by employing SHAP to provide
model interpretability. This analysis enables a psycholinguistic
comparison of the top features driving predictions, validating
how models map linguistic cues to psychological constructs.
Experimental results show that traditional ensemble models such
as XGBoost and Random Forest outperform transformer-based
architectures in classification, achieving an F1 score of 0.589 and
0.550 respectively. Transformer models such as RoBERTa exhibit
competitive results in regression with average mean squared
errors around 0.088-0.089. The observed performance gap is
mainly attributed to the limited size of the dataset which restricts
the data hungry transformer models from fully leveraging their
contextual understanding capabilities. We highlight the trade-offs
between model complexity and data availability; establishing an
interpretable baseline for future work on scalable, personality-
aware NLP systems.
